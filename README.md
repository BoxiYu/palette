# palette

数学讲解视频的六套配色，为 Manim 设计。每套的颜色角色一致（背景、文字、对象 A/B/C、结论、错误、次要），可以直接互换。

## 用法（Manim）

```python
from palettes import XUAN as P
config.background_color = P["BG"]
C_A, C_B, C_C = P["C_A"], P["C_B"], P["C_C"]
```

透明度和描边宽度等参数也在 `palettes.py` 里。其他工具可以读 `palette.json`。
